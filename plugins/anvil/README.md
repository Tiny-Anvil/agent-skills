# anvil

The first plugin in the Tiny Anvil marketplace: 13 skills and 5 commands for building whole apps (.NET + Vue, CI/CD,
deployment) and games (Godot, Blender, audio) autonomously, evidence first.

Install, how it works and the full skill list: see the [repository README](../../README.md).
Track guides: [app builds](../../docs/app-builds.md) · [game builds](../../docs/game-builds.md) ·
[other agents and models](../../docs/other-agents.md).
